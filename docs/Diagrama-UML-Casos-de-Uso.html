Diagrama de casos de uso

Fronteira do sistema = retângulo. Caso de uso = elipse. Ator = boneco à esquerda. Linha contínua = associação. Linha tracejada com «include» = passo obrigatório. Linha tracejada com «extend» = comportamento opcional. A execução de código é interna ao sistema (não é ator).
